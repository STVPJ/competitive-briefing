# AI Coding Assistants — Competitive Briefing

*Tuesday, 20 October 2026*

Kestrel Code moved first on autonomous pull requests this morning, and Tern Labs answered on price. Practitioners are already counting the review hours.

## Product & Feature News

### Kestrel Code launches background agents that open pull requests on their own

Kestrel's new background agents pick up tickets from an issue tracker, work in a cloud sandbox, run the test suite and open a pull request for human review. Team plan customers get 200 agent hours a month. "We want the agent to be the teammate who never forgets the boring ticket," said chief executive Mara Quill.

*Source: [DevWire, 20 October 2026](https://devwire.example/2026/kestrel-code-background-agents)*

**Why it matters:** This is the first rival to sell agent hours as a plan allowance rather than a usage charge. If Acme Assist's agent work stays usage-priced, Kestrel will look cheaper for the chore-heavy teams we target.

## Pricing & Packaging

### Tern Labs halves Tern CLI Pro to $12 a month and adds a free tier

Tern Labs has cut the price of its terminal coding agent in half and introduced a free tier capped at 50 agent runs a month. Analysts quoted by The Stack Report read it as "a land-grab ahead of larger rivals' pricing changes".

*Source: [The Stack Report, 20 October 2026](https://stackreport.example/news/tern-cli-pricing-free-tier)*

**Why it matters:** A free tier with real agent runs resets what individual developers expect to try before they buy, which is where our team-plan funnel starts.

## Market & Regulatory

### Regulator opens consultation on AI-written code in safety-critical software

A national software-safety regulator has opened a 12-week consultation on whether AI-generated code in safety-critical systems should carry provenance records, and whether vendors of coding assistants should publish evaluation results. Responses close in January.

*Source: [Policy Desk, 20 October 2026](https://policydesk.example/consultation-ai-code-safety-critical)*

**Why it matters:** Provenance records would favour assistants that already log which lines they wrote. Worth a view from the platform team before the response window closes.

### Survey: 41% of engineering managers now label AI-assisted pull requests

A survey of 600 engineering managers found 41% now track AI-assisted pull requests separately, mostly to measure review load rather than to restrict use.

*Source: [The Stack Report, 19 October 2026](https://stackreport.example/research/ai-pr-tracking-survey)*

**Why it matters:** Buyers are starting to measure review cost, not just output. That is the metric Kestrel's launch will be judged on.
